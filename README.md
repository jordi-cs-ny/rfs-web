# redfrogstrategy.com

Static website for Red Frog Strategy Corp (HTML/CSS, no build step, no cookies or tracking).
Hosted on GitHub Pages from `main` (root).

- `assets/logo.svg`: vector trace of the existing low-resolution PNG logo (frog, rule, RED FROG). "Strategy" is live text.
- `assets/favicon.svg`: frog only.
- Font: Archivo (SIL Open Font License), self-hosted.
- Before launch on the custom domain: remove `<meta name="robots" content="noindex">` from the pages.
